# 하네스 전환 및 검증 기록

2026-09-10. AGENTS.md를 공통 지침으로 유지하며 Astra를 기본으로 사용하고,
필요할 때 명시적으로 다른 모델을 선택하는 구조를 구현했습니다.

## 구현한 흐름

사람의 명세·테스트 검토 → 커밋된 기준 승인 → 테스트 하나 삽입 → 실패 근거
확인 → 구현 워커 → 보호 파일 검사·포맷·린트·전체 테스트 → 체크·커밋 → 최종
게이트 → 별도 맥락의 읽기 전용 리뷰 순서로 진행합니다. 이미 통과하는 항목은
그 사실을 기록하고 구현 호출을 생략합니다. Go 미정의 심볼의 build-red는
별도 승인 옵션을 쓸 때만 허용하며, 최종 성공은 실제 실행 결과로 판단합니다.

기본 정책은 Astra입니다. `economy.example.json`은 Sol 구현·Astra 리뷰와 진단
인계 후 Astra 구현을 보여줍니다. `selected` 모드에서는 선택한 워커를 유지합니다.
모델을 바꾸어도 승인 기준과 검증 강도는 바뀌지 않습니다. 호출 한도는 승인별
누적이며, 실패 자체가 자동 승급의 근거가 되지 않습니다.

검증 결과: Python 자동 테스트 **91개 전부 통과**(Vitest 생략 없음),
별도 셸 회귀 검사 **8개 통과**. 루트 훅 연결·워크스페이스·brain 인덱스·
diff 공백 검사도 통과했습니다.

## 검증한 경계

| 경계 | 확인한 동작 |
|---|---|
| 승인 | 명시적 승인 필요, 재실행 시 기준 유지, 변경 기준은 명시적 재승인 |
| 테스트 | 본문·헤더·픽스처 변조 거부, 주석·skip·이름만 있는 가짜 성공 거부 |
| 실제 실행 | Go JSON, Node TAP, 로컬 Vitest JSON 결과에서 실행·성공 확인 |
| 작업 상태 | staged·untracked 변경 거부, 자동 stash/reset 없음, 별도 worktree 잠금 |
| 재개 | 인계 근거 보존, 호출 예산 유지, 준비 실패·커밋 실패 복구 |
| 커밋 | 검증한 내용과 실제 tree·parent 비교, 훅이 바꾼 미검증 결과 거부 |
| 취소 | 워커와 테스트 프로세스 그룹 종료, 살아 있는 고아 작업자와 중복 실행 거부 |
| 정리 검사 | Git 훅이 없어도 포맷·린트 직접 실행, gofmt 목록 출력도 실패 처리 |
| 리뷰 | 새 맥락, 저장소·index 변경 거부, 리뷰를 확인한 HEAD에 연결 |
| 어댑터 | Codex 실행 인수·결과 스키마·사용량 이벤트를 가짜 실행 파일로 검증 |
| 설치 | 기존 사용자 훅 보존, root/worktree 지원, 실제 Git 훅 경로 확인 |

재현 명령:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py'
bash tdd-set/tests/gate-verbatim.sh
bash tdd-set/tests/next-entry.sh
bash tdd-set/tests/probe-go-imports.sh
python3 scripts/setup.py . --check
python3 scripts/brain-index.py . --check
python3 scripts/workspace-check.py .
git diff --check
```

실제 Vitest 테스트까지 실행하려면 `SOBAYA_TEST_VITEST_ROOT`를 Vitest가 이미
설치된 앱 경로로 지정합니다. 이번 실행에서는 기존 설치를 읽기만 했습니다.
검증용 앱은 임시 Git 저장소이며, 기존 앱 명세·테스트·구현은 수정하지 않았습니다.

## 범위와 한계

루트 CLAUDE.md, .claude의 지침 연결·명령·훅·설정과 모델 전용 유지보수 가드를
제거했습니다. .codex/hooks.json은 파일을 보존하고 제거된 스크립트 연결만
비웠습니다. 과거 비용·훅 관찰은 archive로 옮겼으며 원출처 표기는 보존했습니다.
루트 Git 훅은 실제로 연결하고 확인했습니다.

독립 앱 저장소의 CLAUDE.md에는 포인터뿐 아니라 고유 지침이 있습니다.
앱 내부 .claude에는 스킬·메모와 실제 worktree도 있습니다. 앱별 지침 이관 범위는
별도 확인을 요청했으며, 이번 공통 하네스 변경에서는 이 데이터를 보존했습니다.

유료 모델 세션은 호출하지 않았습니다. 따라서 실제 Codex 인증·모델 접근,
장시간 작업 품질·비용은 이 결과에 포함되지 않습니다. 외부 제공자는 공통
command 어댑터 계약을 구현해야 합니다. 세션 재사용과 통화 기준 예산 상한은
구현한 기능이 아닙니다. 테스트는 상태 전이와 오류 차단의 근거이며, 임의 앱의
명세가 완전하거나 허용된 사용자 명령이 적대적이지 않다는 보증은 아닙니다.
