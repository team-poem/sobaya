# Run one TDD cycle

Provider-neutral task reference; APP means apps/<name>.

Read the app intent and tdd-set/AGENTS.md. Select the next scenario, write one
failing test, make it pass and optionally refactor at GREEN. Work directly or
use step.sh APP for the single concrete candidate. No exact-test approval or
mandatory review. Inspect real test results, explain useful learning, then
choose the next scenario within the authorized task.
